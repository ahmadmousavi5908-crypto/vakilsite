# SEO / AEO / GEO — مرکز راهبرد رشد Vakilsite

این پوشه مرجع راهبرد کشف، اعتبار، جذب موکل و سنجش عملکرد جست‌وجوی سایت است.

## اسناد

## ترتیب اجرا

1. ابتدا دامنه canonical، HTTPS و دسترسی به Search Console و Bing Webmaster تأیید شود.
2. سپس ممیزی فنی، ایندکس، sitemap، schema و کیفیت محتوای موجود انجام شود.
3. بعد از تثبیت منابع و بازبینی انسانی، صفحات خدمات و محتوای مرجع توسعه یابد.
4. در نهایت Local SEO، تبدیل درخواست و تحلیل AI visibility بر اساس داده واقعی بهینه شود.

## قواعد

- هیچ رتبه، citation، تعداد موکل یا نتیجه تجاری تضمین نمی‌شود.
- صفحات کم‌ارزش، تکراری و doorway تولید نمی‌شوند.
- هیچ ادعای حرفه‌ای، حقوقی، آمار موفقیت یا review بدون سند منتشر نمی‌شود.
- محتوای حقوقی پیش از index شدن باید از نظر منبع و اعتبار زمانی بازبینی شود.
- SEO، AEO و GEO بر یک پایه مشترک کیفیت و اعتماد بنا می‌شوند؛ تاکتیک فریب موتور یا schema ساختگی ممنوع است.
