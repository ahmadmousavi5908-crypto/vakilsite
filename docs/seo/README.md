## ترتیب اجرا
1. دامنه canonical، HTTPS و دسترسی واقعی Search Console/Bing Webmaster را تأیید کن.
2. ممیزی فنی، ایندکس، sitemap، schema و کیفیت محتوای موجود را انجام بده.
3. با داده واقعی، مشکلات فنی و فرصت‌های محتوا را اولویت‌بندی کن.
4. فقط پس از بازبینی انسانی، صفحات خدمات و محتوای مرجع توسعه یابد.
5. Local SEO و تبدیل درخواست بر اساس اطلاعات واقعی و کیفیت سرنخ بهینه شود.

## قواعد
- هیچ رتبه، citation، تعداد موکل یا نتیجه تجاری تضمین نمی‌شود.
- صفحات کم‌ارزش، تکراری و doorway تولید نمی‌شوند.
- هیچ ادعای حرفه‌ای، حقوقی، آمار موفقیت یا review بدون سند منتشر نمی‌شود.
- محتوای حقوقی پیش از index شدن باید از نظر منبع و اعتبار زمانی بازبینی شود.
- SEO، AEO و GEO بر یک پایه مشترک کیفیت و اعتماد بنا می‌شوند؛ تاکتیک فریب موتور یا schema ساختگی ممنوع است.
- Google News فقط پس از احراز چرخه واقعی خبر و الزامات ناشر بررسی می‌شود؛ sitemap خبری برای مقاله evergreen ساخته نمی‌شود.
