## LCP باقی‌مانده و اصلاح بعدی

گزارش LCP نشان داد تصویر اصلی وکیل در صفحه خانه و معرفی، با وجود `fetchpriority="high"` هنوز `loading="lazy"` داشت. این دو تصویر در trace به‌عنوان LCP شناسایی شدند. در commit بعدی، `loading="eager"` به همان دو تصویر اضافه و آزمون HTTP نیز برای آن الزامی شده است.

این اصلاح هنوز در زمان ثبت این سند اندازه‌گیری نشده است. پس از اجرای Lighthouse جدید باید LCP دوباره مقایسه شود. هیچ تغییر کیفیت تصویر، crop، اندازه، ظاهر یا asset در این اصلاح مجاز نیست.
