# راه‌اندازی MAVIS در Termux

این راهنما برای دریافت و اجرای نسخه تولیدی سایت روی Android/Termux است. توسعه، ویرایش کد و عیب‌یابی جزئی در Termux انجام نمی‌شود.

## پیش‌نیاز

- نسخه رسمی و به‌روز Termux
- Node.js نسخه 20.9 یا جدیدتر؛ نسخه 24 LTS توصیه می‌شود
- npm، Git و curl
- دست‌کم 1.5 گیگابایت فضای خالی

در صورت نبود ابزارها، یک‌بار اجرا کنید:

```bash
pkg install -y git nodejs-lts npm curl
```

اسکریپت نصب عمداً `pkg upgrade` یا تغییر سراسری تنظیمات Termux را اجرا نمی‌کند.

## اجرای یک‌مرحله‌ای

تا پیش از ادغام PR نهایی، این دستور صرفاً برای آزمون پذیرش شاخه نامزد است؛ پس از ادغام، ref اسکریپت به شاخه انتشار منتقل می‌شود:

```bash
curl -fsSL https://raw.githubusercontent.com/ahmadmousavi5908-crypto/vakilsite/feature/mavis-final-verification-20261109/scripts/termux/install.sh | bash
```

اسکریپت:
1. محیط Termux، نسخه Node.js، ابزارهای لازم و فضای خالی را بررسی می‌کند.
2. سورس را از شاخه مشخص‌شده GitHub دریافت یا در صورت سالم و بدون تغییر بودن پوشه قبلی به‌روزرسانی می‌کند.
3. فایل محیط محلی را با دسترسی محدود ایجاد می‌کند؛ چت عمومی MAVIS و پذیرش درخواست در حالت غیرفعال باقی می‌مانند.
4. وابستگی‌ها را دقیقاً مطابق lockfile دریافت می‌کند.
5. خروجی تولیدی را با Webpack می‌سازد.
6. سرور را فقط روی `127.0.0.1:3002` اجرا می‌کند و پاسخ HTTP را بررسی می‌کند.

نشانی محلی: `http://127.0.0.1:3002`

برای توقف سرور، در همان نشست `Ctrl+C` را بزنید.

## مسیر نصب و گزارش

- پوشه پروژه: `~/downloads/vakilsite-mavis-termux`
- گزارش اجرای سرور: `.termux-start.log` در پوشه پروژه
- فایل تنظیمات محلی: `.env.local` با مجوز دسترسی محدود

برای انتخاب پوشه دیگری:

```bash
MAVIS_DIR="$HOME/downloads/vakilsite-mavis-termux-2" bash -c "$(curl -fsSL https://raw.githubusercontent.com/ahmadmousavi5908-crypto/vakilsite/feature/mavis-final-verification-20261109/scripts/termux/install.sh)"
```

## مرزهای ایمنی

- اسکریپت فایل‌های موجود در پوشه مقصد را بدون بررسی سلامت مخزن و پاک بودن تغییرات محلی بازنویسی نمی‌کند.
- کلیدهای Supabase، OpenAI یا Google در مخزن یا اسکریپت قرار نمی‌گیرند.
- قابلیت‌های عمومی MAVIS و ذخیره درخواست‌ها به‌صورت پیش‌فرض خاموش هستند.
- آرشیو Mother Two و داده‌های محرمانه وارد GitHub یا این فرایند دانلود نمی‌شوند.
- OCR و Docling جزء نصب پایه نیستند.
- اگر ساخت یا آزمون سلامت شکست بخورد، گزارش ثبت می‌شود و باید اصلاح در GitHub انجام شود؛ فایل‌های پروژه در Termux را دستی دست‌کاری نکنید.
