# دروازه مجازبودن جغرافیایی OpenAI API در MAVIS

تاریخ بررسی رسمی: 2026-11-09  
وضعیت: مسدودکننده فعال‌سازی هرگونه Public OpenAI Chat برای مخاطبان خارج از کشورهای پشتیبانی‌شده.

## یافته رسمی

فهرست رسمی OpenAI API تصریح می‌کند که دسترسی API فقط از کشورهای درج‌شده پشتیبانی می‌شود و دسترسی‌دادن به سرویس از خارج این فهرست ممکن است به مسدود یا تعلیق‌شدن حساب منجر شود. در فهرست بررسی‌شده:
- Germany درج شده است.
- Iran درج نشده است؛ طبق همان سیاست، نبود نام کشور به معنی پشتیبانی‌نشدن API در آن محل است.

این قاعده فقط محل استقرار سرور یا کشور صاحب کلید را پوشش نمی‌دهد؛ مستند رسمی جداگانه هشدار می‌دهد که دسترسی یا ارائه دسترسی از کشور پشتیبانی‌نشده می‌تواند موجب مسدودشدن حساب شود. بنابراین استقرار backend در یک کشور مجاز به‌تنهایی مجوز ارائه قابلیت OpenAI به بازدیدکننده‌ای در کشور پشتیبانی‌نشده نیست.

## تصمیم MAVIS

1. Public Chat همچنان خاموش می‌ماند؛ تنظیم \`MAVIS_PUBLIC_ENABLED=false\` نباید تغییر کند.
2. هیچ مسیر پراکسی، VPN، تغییر IP، واسطه‌سازی یا روش دورزدن محدودیت جغرافیایی طراحی یا اجرا نمی‌شود.
3. برای بازدیدکنندگان داخل ایران، قابلیت‌های مستقل از OpenAI باید در دسترس بمانند: جست‌وجوی قطعی در منابع عمومی، بسته آفلاین، فرم پذیرش اولیه و ارجاع انسانی؛ هرکدام فقط در محدوده مجوز و زیرساخت خود.
4. اگر در آینده دستیار مولد برای مدیر یا مخاطبان کشور پشتیبانی‌شده فعال شود، احراز محل استفاده، شرایط حساب/API، شرایط قراردادی، پردازش داده و محدوده کاربران باید پیش از فعال‌سازی جداگانه بررسی و ثبت شود.
5. برای ارائه عمومی چندکشوری، معماری باید بر اساس region eligibility، مسیریابی مجاز provider و fail-closed طراحی شود. اگر محل کاربر با اطمینان تعیین نشود، مسیر OpenAI اجرا نشود.
6. هر provider جایگزین نیز باید از نظر مجازبودن در محل استفاده، حفاظت داده، قرارداد، کیفیت فارسی و امکان استناد حقوقی بررسی شود؛ «جایگزین» به معنی مجازبودن خودکار نیست.
7. داده موکل یا پرونده محرمانه نباید صرفاً به دلیل قرارداشتن اپراتور در کشور پشتیبانی‌شده به provider ارسال شود؛ این موضوع نیازمند مجوز، مبنای پردازش و کنترل دسترسی مستقل است.

## معیار بازگشایی

- مستند رسمی کشورها در زمان تصمیم دوباره بررسی و نسخه/تاریخ ثبت شود.
- محل واقعی درخواست‌کننده از مسیر قابل اعتماد و بدون اتکا به هدر قابل جعل احراز شود.
- برای کاربران پشتیبانی‌نشده، provider مولد مسدود و fallback قطعی/انسانی فعال باشد.
- برای هر منطقه، provider، data flow، retention، consent، logging و subprocessors تأیید شوند.
- تست شود که تغییر دستی \`MAVIS_PUBLIC_ENABLED\` یا \`MAVIS_PROVIDER\` به‌تنهایی محدودیت جغرافیایی را دور نمی‌زند.
- مالک پیش از فعال‌سازی عمومی تأیید صریح بدهد.
