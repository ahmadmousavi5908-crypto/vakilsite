# دروازه دسترسی Google Trends API برای MAVIS

تاریخ بررسی: 2026-11-09  
وضعیت: اتصال برنامه‌ای غیرفعال تا زمان پذیرش رسمی حساب در Alpha و دریافت قرارداد/مجوز معتبر.

## یافته‌های رسمی

مستند رسمی Google Search Central برای Google Trends API در زمان بررسی، این API را در مرحله Alpha معرفی می‌کند و صراحتاً از توسعه‌دهندگان می‌خواهد برای دسترسی زودهنگام درخواست ثبت کنند. همان صفحه می‌گوید دسترسی هنوز برای همه باز نشده و پذیرش محدود است.

قابلیت‌های اعلام‌شده:
- پنجره داده چرخشی پنج‌ساله
- تجمیع روزانه، هفتگی، ماهانه و سالانه
- داده منطقه‌ای و زیرمنطقه‌ای
- مقایسه/ادغام چند درخواست و مقیاس‌بندی سازگارتر

این قابلیت‌ها توصیف محصول Alpha هستند؛ endpoint، schema، روش احراز هویت، سهمیه و شرایط استفاده حساب MAVIS را اثبات نمی‌کنند.

## تصمیم معماری

1. Google Search Console API فعلی، مسیر تحلیلی عملیاتی و فقط‌خواندنی باقی می‌ماند.
2. Google Trends API تا زمان پذیرش رسمی Alpha و دریافت مستندات اختصاصی حساب پیاده‌سازی نمی‌شود.
3. هیچ scraping خودکار از رابط وب Trends، دورزدن محدودیت‌ها یا استفاده از endpoint خصوصی انجام نمی‌شود.
4. در نسخه فعلی، پیشنهاد کلیدواژه از متن مقاله و داده واقعی Search Console دو خروجی مجزا هستند؛ هیچ‌کدام نباید به‌عنوان حجم جست‌وجوی Google Trends معرفی شوند.
5. هر خروجی Trends در آینده باید region، timeframe، interval، category، search property، timestamp، timezone، داده خام و وضعیت Alpha را همراه خود نگه دارد.
6. مقایسه موضوعات حقوقی ایران و استان خوزستان باید با داده منطقه‌ای واقعی و با احتیاط نسبت به حجم کم داده انجام شود؛ امتیاز نسبی Trends معادل تعداد جست‌وجو نیست.

## معیار بازگشایی

پیش از ساخت connector:
- پذیرش رسمی حساب در Alpha یا انتشار دسترسی عمومی
- دریافت مستندات endpoint و نسخه API
- تأیید OAuth/API credential و حداقل scope
- تأیید schema، واحد/مقیاس شاخص، region codes، time intervals و quota
- تأیید Terms و محدودیت ذخیره‌سازی/بازنشر
- تست واقعی با property/use case مجاز و ثبت timestamp و provenance
- آزمون کیفیت برای داده فارسی و استان/شهر، بدون جعل تفکیک مکانی

## منابع رسمی

- Google Search Central — Google Trends API Alpha: https://developers.google.com/search/apis/trends
- Google Search Console Search Analytics API (جدا از Trends): https://developers.google.com/webmaster-tools/v1/searchanalytics/query

## محدودیت شواهد

این بررسی نشان می‌دهد API برنامه‌ای Trends در صفحه رسمی هنوز Alpha و محدود به پذیرش است. وضعیت دسترسی اختصاصی حساب کاربر بررسی نشده است؛ بنابراین نباید گفت کاربر واجد شرایط نیست یا API قطعاً در دسترس او نیست.
