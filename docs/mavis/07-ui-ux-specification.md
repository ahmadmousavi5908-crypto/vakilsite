# 07 — مشخصات تجربه کاربری

## 1. هویت

نام: MAVIS | ماویس  
شخصیت: دستیار هوشمند موسوی  
زبان: فارسی  
جهت: RTL  
لحن: حرفه‌ای، روشن، محترمانه و قابل فهم

ماویس باید آشکارا اعلام کند هوش مصنوعی است و وکیل یا جایگزین مشاوره اختصاصی نیست.

## 2. Launcher

- شناور و مستقل از دکمه‌های فعلی سایت.
- در موبایل و دسکتاپ جایگاه و اندازه جداگانه دارد.
- بالاتر از دکمه «معرفی وکیل» قرار می‌گیرد.
- هیچ wrapper، state یا CSS مشترکی با دکمه معرفی وکیل ایجاد نمی‌کند.
- رنگ، سایه، انیمیشن و موقعیت دکمه موجود معرفی وکیل تغییر نمی‌کند.
- محدوده کلیک و focus قابل دسترس است.
- prefers-reduced-motion رعایت می‌شود.

- از رویداد `vakilsite:dock-open` برای بستن پنل داک‌های دیگر استفاده می‌کند.
- تا زمان فعال‌شدن runtime، پنل فقط معرفی شفاف و پیوند به صفحه دستیار را نمایش می‌دهد؛ وضعیت آنلاین جعلی ممنوع است.
- پرتره SVG موقت است؛ asset سه‌بعدی مصوب باید جداگانه اضافه شود.

## 3. شخصیت بصری

از تصویر مرجع ذخیره‌شده شخصیت ماویس استفاده می‌شود: مرد جوان کارتونی سه‌بعدی با موهای تیره موج‌دار، عینک مشکی، ریش مرتب، کت سرمه‌ای و جزئیات طلایی، نماد عدالت و کتاب حقوقی.

تصویر مرجع نباید بدون ضرورت بازتولید شود. نسبت تصویر، crop و نسخه سبک‌شده برای موبایل جداگانه بررسی می‌شوند.

## 4. پنجره گفتگو

اجزای لازم:
- Header با نام و وضعیت سرویس.
- پیام معرفی و هشدار حریم خصوصی.
- فهرست پیام‌ها با تفکیک نقش.
- ورودی متن و دکمه ارسال.
- حالت loading و امکان توقف در صورت streaming.
- خطای قابل فهم و امکان retry امن.
- پاک‌سازی/شروع مکالمه جدید.
- نمایش محدودیت سرویس و راه تماس انسانی.

## 5. حالت‌ها

- idle
- connecting
- ready
- sending
- receiving
- stopping
- error
- rate_limited
- unavailable

تغییر حالت باید قابل پیش‌بینی باشد و از ارسال تکراری جلوگیری کند.

## 6. دسترس‌پذیری

- keyboard navigation.
- focus visible و مدیریت focus در modal.
- aria-label و نقش مناسب.
- کنتراست کافی.
- اندازه لمس مناسب.
- اعلام وضعیت پیام برای screen reader.
- رعایت reduced motion.
- جلوگیری از اسکرول افقی در RTL.

## 7. امنیت UI

- متن پاسخ مدل به‌صورت متن عادی render شود.
- HTML خام مدل اجرا نشود.
- لینک‌ها با allowlist پروتکل و ویژگی‌های امن پردازش شوند.
- داده محرمانه در localStorage یا analytics عمومی ذخیره نشود.
- پیام هشدار قبل از ارسال اطلاعات حساس نمایش داده شود.

## 8. رگرسیون سایت

پیش از merge باید بررسی شود:
- دکمه معرفی وکیل در همان مختصات و اندازه قبلی است.
- انیمیشن و رفتار آن تغییر نکرده.
- فهرست موبایل و مشاوره با Launcher تداخل ندارند.
- صفحات و منوهای فعلی سالم‌اند.
- رابط جدید در viewportهای رایج Android و desktop تست شده است.
